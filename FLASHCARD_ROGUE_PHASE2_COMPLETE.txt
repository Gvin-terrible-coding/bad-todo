- Recruit to expand team

## 🛠️ Technical Deep Dive

### Animation Architecture

**Phaser Tweens System:**
```javascript
// Attack animation
this.tweens.add({
  targets: pokemonSprite,
  x: `+=${offsetX}`,     // Move toward opponent
  yoyo: true,            // Return to original
  duration: 200,
  ease: 'Power1'
});

// HP bar animation
this.tweens.add({
  targets: healthBar,
  width: newWidth,       // Animate to new width
  duration: 300,
  onUpdate: (tween) => {
    // Update color during animation
  }
});
```

**Visual Effects:**
```javascript
// Damage flash
target.setTint(0xffffff);  // Apply white tint
setTimeout(() => target.clearTint(), 100);  // Remove after 100ms

// Floating damage number
const text = this.add.text(x, y, damage);
this.tweens.add({
  targets: text,
  y: y - 60,             // Move up
  alpha: 0,              // Fade out
  duration: 1000
});
```

### Leveling Architecture

**XP Flow:**
```javascript
// Battle won
const xpGain = calculateXpGain(enemy);  // 20 × enemy.level
playerPokemon.exp += xpGain;

// Check level up
const levelData = checkLevelUp(playerPokemon);
if (levelData.leveled) {
  applyLevelUp(playerPokemon, levelData.newLevel);
  // → Stats recalculated
  // → HP restored
  // → Message displayed
}
```

**State Management:**
```javascript
gameState = {
  isRunning: boolean,
  currentWave: number,
  score: number,
  playerTeam: Pokémon[],
  isShowingReward: boolean,
  rewardCandidates: Pokémon[3],
  ...
}
```

### Reward System Architecture

**Flow:**
```javascript
// After boss battle (wave % 5 === 0)
const isBossWave = newWave % WAVES_PER_GYM_LEADER === 0;

if (isBossWave) {
  // Generate 3 random Pokémon
  const rewardCandidates = [
    generateRandomPokemon(level, level+3),
    generateRandomPokemon(level, level+3),
    generateRandomPokemon(level, level+3)
  ];
  
  // Show modal
  setGameState({...prev, isShowingReward: true, rewardCandidates});
}

// User selects one
selectReward(pokémon) {
  playerTeam.push(pokémon);  // Add to team
  startBattle();             // Continue
}
```

### XP Scaling

```javascript

export function calculateXpGain(enemy) {
  return enemy.level * 50;  // Changed from 20 to 50 for faster leveling
```

🎯 COMMON TASKS
═══════════════════════════════════════════════════════════════════════════

WANT TO: Play the game
───────────────────────
1. Read: README_FLASHCARD_ROGUE.md (5 min)
2. Add flashcards to StudyZone
3. Click "Flashcard Rogue" tab
4. Click "Start Adventure!"
5. Battle Pokémon!

WANT TO: Understand how it works
─────────────────────────────────
1. Read: FLASHCARD_ROGUE_GUIDE.md (20 min)
2. Browse: src/FlashcardRogue.js
3. Browse: src/game-data.js
4. Read: FLASHCARD_ROGUE_STATE_MACHINE.md (15 min)

WANT TO: Customize the game
────────────────────────────
1. Read: FLASHCARD_ROGUE_QUICK_START.md (Extension section)
2. Edit: src/game-data.js
   ├─ GAME_CONFIG (difficulty)
   ├─ POKEMON_SPECIES (add Pokémon)
   ├─ MOVES (add moves)
   └─ GYM_LEADERS (add bosses)
3. Test your changes

WANT TO: Debug or troubleshoot
───────────────────────────────
1. Check: GETTING_STARTED_FLASHCARD_ROGUE.txt (Troubleshooting section)
2. Open: Browser DevTools (F12)
3. Check: Console for errors
4. Add: console.log() statements in code
5. Reference: FLASHCARD_ROGUE_QUICK_START.md (Debugging tips)

WANT TO: Add a new Pokémon
──────────────────────────
1. Open: src/game-data.js
2. Find: POKEMON_SPECIES object
3. Add entry:
   newpokemon: {
     id: 'newpokemon',
     name: 'New Pokémon',
     type: ['type1', 'type2'],
     baseStats: { hp: 50, atk: 60, def: 50, spa: 60, spd: 50, spe: 50 },
     learnable: ['move1', 'move2', 'move3', 'move4'],
     baseExp: 100,
   }
4. Save file
5. Play!

WANT TO: Change game difficulty
────────────────────────────────
1. Open: src/game-data.js
2. Find: GAME_CONFIG object
3. Edit these values:
   - CORRECT_ANSWER_BONUS_DAMAGE (1.2 = 20% bonus)
   - WAVES_PER_GYM_LEADER (5 = boss every 5 waves)
   - STARTING_TEAM_SIZE (3 = team of 3)
4. Save file
5. Restart game

WANT TO: Modify damage calculation
───────────────────────────────────
1. Open: src/game-data.js
2. Find: calculateDamage() function
3. Read the comments to understand the formula
4. Make your changes carefully
5. Test thoroughly!

🚀 GETTING STARTED SUPER QUICK (2 MINUTES)
═══════════════════════════════════════════════════════════════════════════

1. Add flashcards to StudyZone: "Q→A" format
2. Click "Flashcard Rogue" tab
3. Click "Start Adventure!"
4. Click a move → answer flashcard
5. Correct = 20% damage boost, Wrong = move fails
6. Defeat enemies to progress waves
7. Survive as many waves as possible!

That's it! Enjoy! 🎮

## 🎮 Feature Details

### Sprite Graphics
```
How it works:
1. Save sprites to: public/pokemon/{species}_{front|back}.gif
2. Game loads automatically on battle
3. Falls back to rectangles if missing
4. Scales properly and looks professional
```

### Status Moves
```
How it works:
1. Growl/other moves use stat_change effect
2. Stat multipliers applied to Pokémon
3. Next turn damage affected by multipliers
4. Example: Growl makes next turn 25% weaker
```

### Held Items
```
How it works:
1. After boss battle, choose item as reward
2. Item equipped to first Pokémon
3. Damage calculation applies item bonus
4. Example: Charcoal makes Fire moves 20% stronger
```

## 🚀 Getting Started

### To See Sprites
1. Get/create Pokémon GIF files
2. Name: `charmander_front.gif`, `charmander_back.gif`
3. Save to: `public/pokemon/`
4. Battle that Pokémon - sprite appears! ✨

### To Use Status Moves
1. Battle any Pokémon
2. Some moves now do stat changes (Growl, etc.)
3. Watch damage calculation change next turn
4. Strategy now matters! 🧠

### To Use Items
1. Defeat a boss (wave 5, 10, 15...)
2. Reward screen shows Pokémon + Item tabs
3. Click Item tab, choose a reward
4. Item equipped automatically 🎁

## 🎮 Features Breakdown

### Sprites
- **Support:** `.gif` format (any Pokémon sprite)
- **Path:** `public/pokemon/{species}_front.gif` and `{species}_back.gif`
- **Fallback:** Rectangles if sprite unavailable
- **Scale:** 2.5x (configurable via GAME_CONFIG.POKEMON_SCALE)

### Status Moves
| Move | Stat | Effect | Duration |
|------|------|--------|----------|
| Growl | ATK | -25% | Until battle end |
| Screech | DEF | -50% | Until battle end |
| Amnesia | SPD | -50% | Until battle end |
| Tailwind | SPE | +50% | Until battle end |
| Sword's Dance | ATK | +50% | Until battle end |
| Dragon Dance | ATK, SPE | +25% | Until battle end |

### Held Items

**Type Boosters (Common - 1.2x boost):**
- Charcoal 🔥 (Fire)
- Mystic Water 💧 (Water)
- Magnet ⚡ (Electric)

**Defensive (Uncommon):**
- Assault Vest 🛡️ (Sp.Def +25%)
- Choice Scarf 🧣 (Speed +30%)
- Float Stone 🪨 (Ground resistance)

**Offensive (Rare):**
- Life Orb 💀 (All moves +30%, recoil framework)
- Choice Specs 👓 (Sp.Atk +50%)

**Utility (Rare):**
- Leftovers 🍽️ (Recovery framework)

## 🔧 Implementation Highlights

### Smart Fallbacks
- Sprites optional - rectangles appear if missing
- Items never break game - just add 0% bonus if not valid
- Status moves work even without specific Pokémon (any can learn them)

### Clean Architecture
- Item data centralized in ITEMS object
- Stat multiplier system isolated in calculateDamage()
- Status move effects isolated in applyStatusMoveEffect()
- Reward logic cleanly separated in handleBattleEnd()

### Extensibility
- Easy to add new status moves (add to MOVES with stat_change effect)
- Easy to add new items (add to ITEMS object)
- Easy to add new sprites (drop in public/pokemon/)
- Easy to modify item effects (edit getItemDamageMultiplier, etc.)

🎮 HOW TO PLAY
═════════════════════════════════════════════════════════════════════════════

1. ADD FLASHCARDS TO STUDYZONE
   Format: "Question→Answer" or "Question>>Answer"
   Example: "What is 2+2?→4"

2. NAVIGATE TO FLASHCARD ROGUE
   Click the "Flashcard Rogue" tab in your sidebar

3. START ADVENTURE
   Click "Start Adventure!" button

4. BATTLE!
   - See your Pokémon (blue) vs enemy Pokémon (red)
   - Click a move button
   - Answer the flashcard question that appears
   - CORRECT answer = 20% damage bonus ✓
   - WRONG answer = move fails ✗
   - Defeat enemies to progress through waves
   - Every 5 waves: Face a Gym Leader boss
   - When Pokémon faints: Send next team member
   - Game ends when all Pokémon fainted


💡 KEY MECHANICS
═════════════════════════════════════════════════════════════════════════════

KNOWLEDGE IS POWER
──────────────────
The unique twist of Flashcard Rogue: players must answer flashcard
questions to use moves. This creates natural integration between
learning and game mechanics.

- Correct answer: Move executes with +20% damage bonus
- Wrong answer: Move fails entirely, opponent gets free turn
- Encourages studying while maintaining game challenge

DAMAGE CALCULATION
──────────────────
Uses simplified Pokémon damage formula:
  base = (((2*level/5+2)*power*attack)/defense)/50 + 2
  
With multipliers:
  × type effectiveness (0.5x, 1x, 2x)
  × correct answer bonus (1.2x)
  × random variance (0.85x-1x)

Example: Pikachu's Thunderbolt on Squirtle
  Base damage: 156
  Type advantage (Electric vs Water): ×2 = 312
  Correct answer: ×1.2 = 374
  Random variance: ×0.92 = 344 damage

WAVE SYSTEM
───────────
Progressive difficulty with scaling enemies:
  Wave 1-4: Random Pokémon, levels 5-8
  Wave 5: Gym Leader boss (Brock with Rhydon) - Level 15
  Wave 6-9: Random Pokémon, levels 8-12
  Wave 10: Gym Leader boss (Misty with Lapras) - Level 15
  Wave 15+: Progressively harder bosses

Your starting team has 3 Pokémon at levels 5, 6, 7
No leveling system in Phase 1 (planned for Phase 2)

PERMADEATH
──────────
Core roguelike mechanic:
  - When Pokémon's HP reaches 0: Permanently removed from team
  - Next team member is sent to battle
  - If all team members faint: GAME OVER
  - Run is lost (in Phase 2: could add save/continue feature)

SCORE SYSTEM
────────────
Points earned for each victory:
  Enemy level × 10 = points
  Example: Defeating Level 15 Gym Leader = 150 points

Running total displays in-game stats bar

📊 TECHNICAL SPECIFICATIONS
═════════════════════════════════════════════════════════════════════════════

PHASER CONFIGURATION:
- Type: AUTO (WebGL or Canvas)
- Resolution: 960×540 pixels
- Physics: Arcade (zero gravity)
- Scene: BattleScene (created fresh each battle)

REACT INTEGRATION:
- Component uses hooks: useState, useEffect, useCallback, useMemo
- Props: studyZoneState, showMessageBox, stats
- Callbacks to Phaser: onQuizRequested, onBattleEnd

STATE MACHINE STATES:
- 'waiting': Player can click move buttons
- 'quiz': Awaiting flashcard answer
- 'executing': Player move executing
- 'battleEnd': Battle concluded
- 'ended': Final state

PERFORMANCE:
- Phaser scene destroyed after each battle (no memory leaks)
- ~60 FPS target
- ~2-5 MB per battle instance
- No accumulating memory over multiple battles

❓ FAQ
═════════════════════════════════════════════════════════════════════════════

Q: Why is the Pokémon HP formula different?
A: Pokémon games use a special formula for HP that includes +level+10,
   making HP more valuable than other stats. This is implemented correctly.

Q: Why 20% damage bonus for correct answers?
A: This balances the educational component:
   - Too low (5%): Feels negligible, no reward for studying
   - Too high (50%): Makes wrong answers feel impossible
   - 20%: Encourages correct answers without trivializing difficulty

Q: Can I change the difficulty?
A: Yes! Edit GAME_CONFIG in game-data.js to adjust:
   - Damage bonuses
   - Boss frequency
   - Team size
   - Any game constant

Q: How do I add Pokémon?
A: Add entries to POKEMON_SPECIES in game-data.js with correct stats.
   They'll automatically be available in random encounters.

Q: Can I remove the quiz requirement?
A: Technically yes (delete the quiz logic), but that's the unique mechanic!
   Instead, consider making quizzes optional per-level in Phase 2.

Q: Why does the game reset on refresh?
A: Phase 1 doesn't save to Firestore. This is planned for Phase 2.
   You could add it yourself using your existing Firestore setup.

Q: Can I play without flashcards?
A: The game warns you to add flashcards first and defaults correct answers
   if none are found (so it won't crash).

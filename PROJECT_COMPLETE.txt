🚀 HOW TO GET STARTED (3 STEPS)
═══════════════════════════════════════════════════════════════════════════

STEP 1: ADD FLASHCARDS
   Go to StudyZone tab
   Add flashcards in format: "Question→Answer"
   Example: "What is 2+2?→4"
   (Need at least 3-5 for good gameplay)

STEP 2: NAVIGATE TO GAME
   Look for "Flashcard Rogue" tab in sidebar
   Click it to open the game

STEP 3: START PLAYING
   Click "Start Adventure!" button
   Battle Pokémon by answering flashcard questions
   Correct answer = move with 20% damage boost ✓
   Wrong answer = move fails ✗
   Survive as many waves as possible!


💡 GAME MECHANICS (QUICK EXPLANATION)
═══════════════════════════════════════════════════════════════════════════

KNOWLEDGE IS POWER:
───────────────────
When you click a move, a flashcard question appears.
- Answer CORRECTLY → Move executes with +20% damage bonus
- Answer WRONG → Move fails, opponent gets free turn

This creates natural integration between studying and gaming!

WAVE PROGRESSION:
─────────────────
Waves 1-4:    Random Pokémon (levels scale with each wave)
Wave 5:       Gym Leader boss - Brock (Level 15)
Waves 6-9:    Random Pokémon (getting stronger)
Wave 10:      Gym Leader boss - Misty (Level 15)
Wave 15:      Gym Leader boss - Lt. Surge (Level 20)
... and so on!

PERMADEATH:
───────────
Your team starts with 3 Pokémon.
If a Pokémon faints (HP reaches 0), it's permanently gone from this run.
When all team members faint → GAME OVER.
This is classic roguelike gameplay!

SCORING:
────────
Points = Enemy Level × 10
Example: Beat a Level 15 boss = 150 points


📊 DAMAGE CALCULATION
═══════════════════════════════════════════════════════════════════════════

The game uses a simplified but realistic Pokémon damage formula:

BASE DAMAGE = (((2*Level/5+2)*Power*Attack)/Defense)/50 + 2

MULTIPLIERS APPLIED:
  × Type effectiveness (0.5x weak, 1x normal, 2x strong)
  × Correct answer bonus (1.2x = +20%)
  × Random variance (0.85x - 1.0x)

EXAMPLE:
  Pikachu (Level 10, Attack 90)
  Using Thunderbolt (Power 90, Electric type)
  Against Squirtle (Defense 65, Water type)
  
  Base damage: 156
  Type advantage (Electric > Water): ×2 = 312
  Correct answer bonus: ×1.2 = 374
  Random variance: ×0.92 = 344 damage
  
  RESULT: Squirtle takes 344 damage!


🎯 GAME CONFIGURATION
═══════════════════════════════════════════════════════════════════════════

Want to change difficulty? Edit GAME_CONFIG in game-data.js:

EASIER GAME:
─────────────
CORRECT_ANSWER_BONUS_DAMAGE: 1.5    (was 1.2)  → 50% bonus
WAVES_PER_GYM_LEADER: 10            (was 5)    → bosses rarer
STARTING_TEAM_SIZE: 6               (was 3)    → more Pokémon

HARDER GAME:
──────────
CORRECT_ANSWER_BONUS_DAMAGE: 1.05   (was 1.2)  → 5% bonus
WAVES_PER_GYM_LEADER: 3             (was 5)    → bosses frequent
STARTING_TEAM_SIZE: 1               (was 3)    → only 1 Pokémon

Just edit the values and save!

## The Details

### 1️⃣ Attack Animation ✅
- **File:** `src/FlashcardRogue.js` lines 368-383
- **What:** Pokémon sprite moves toward opponent, returns to original position
- **Player:** Moves right (+50px), then back
- **Enemy:** Moves left (-50px), then back
- **Time:** 200ms (100ms out + 100ms back)
- **Currently:** Active in every attack

### 2️⃣ Damage Flash ✅
- **File:** `src/FlashcardRogue.js` lines 386-401
- **What:** Hit Pokémon flashes white on impact
- **Effect:** Sprite turns white, dims to 70% opacity, restores
- **Time:** 100ms
- **Currently:** Active on every hit

### 3️⃣ Damage Popup ✅
- **File:** `src/FlashcardRogue.js` lines 404-426
- **What:** Floating damage number with color feedback
- **Colors:**
  - 🟡 Yellow = Super effective (larger text)
  - ⚪ White = Normal damage
  - ⚫ Gray = Not very effective
- **Animation:** Rises 60px while fading out
- **Time:** 1000ms
- **Auto-destroys:** Yes (prevents memory leaks)
- **Currently:** Active on every hit

### 4️⃣ Health Bar Animation ✅
- **File:** `src/FlashcardRogue.js` lines 429-469
- **What:** HP bar smoothly decreases with color changes
- **Colors (Dynamic):**
  - 🟢 Green = > 50% HP
  - 🟡 Yellow = 25-50% HP
  - 🔴 Red = < 25% HP
- **Time:** 300ms
- **Currently:** Active after every damage calculation

## Where They're Used

### In Player Turns
```javascript
executePlayerMove() {
  await this.animateAttack(this.playerSprite, true);        // Attack animation
  // ... damage calculation ...
  this.animateDamageFlash(this.enemySprite);               // Flash
  this.createDamagePopup(damage, x, y, effectiveness);      // Popup
  this.animateHealthBar(this.enemyPokemon, newHp, false);   // HP bar
}
```

### In Enemy Turns
```javascript
executeEnemyTurn() {
  await this.animateAttack(this.enemySprite, false);        // Attack animation
  // ... damage calculation ...
  this.animateDamageFlash(this.playerSprite);              // Flash
  this.createDamagePopup(damage, x, y, effectiveness);      // Popup
  this.animateHealthBar(this.playerPokemon, newHp, true);   // HP bar
}
```
